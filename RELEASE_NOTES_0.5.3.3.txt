Photo Doctor 0.5.3.3 — DEFECT MAP SELECTION SYNC

Что изменено
- «Карта дефектов» по умолчанию показывает только кандидаты, отмеченные в колонке «Лечить».
- Снятие/установка галочки «Лечить» мгновенно обновляет карту.
- На вкладке «Дефекты» добавлен режим «Показывать все найденные на карте».
- Диагностический режим «все найденные» не меняет набор кандидатов, выбранных для лечения.
- Подсветка выбранной строки корректно пересчитывается после фильтрации карты и больше не указывает на соседний кандидат.
- Информационная строка показывает: найдено / выбрано для лечения / реально отображается на карте.

Совместимость
- Формат БД не менялся.
- Повторный анализ фотографий из-за этой UI-правки не требуется.
- Существующие D/N/U-метки и выбранные цели лечения сохраняют прежний смысл.

Проверка
- 390/390 тестов проекта PASS.
- Добавлены отдельные regression-тесты фильтрации defect-map и remap индекса выбранной строки.
