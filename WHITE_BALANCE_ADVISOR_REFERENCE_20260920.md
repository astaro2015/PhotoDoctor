# WB Advisor v1 — контрольный разбор 2026-09-20

Контрольный набор пользователя содержал три версии одного домашнего кадра:
- исходник;
- Photoshop «Автотон»;
- Photoshop «Автоматическая цветовая коррекция».

Изображения в исходный архив Photo Doctor не включаются.

## Поведение WB Advisor

На исходнике полный pipeline Photo Doctor 0.5.3.14 получил примерно:
- тёплый цветовой сдвиг;
- техническая поправка температуры около -2574 K;
- рекомендуемая поправка около -2024 K;
- tint около +6.8;
- нейтрализация около 79%;
- сохранение атмосферы исходного света около 21%;
- уверенность около 76%.

На версии Photoshop «Автотон» советник всё ещё обнаруживает тёплый сдвиг и рекомендует дополнительное охлаждение. Это ожидаемо: автотон меняет тональный диапазон, но не обязан полностью исправлять WB.

На Photoshop «Автоцвет» советник получает почти нейтральный результат: рекомендуемая поправка температуры около -36 K, correction_needed=false.

## Архитектурный вывод

V1 не является нейросетью. Это гибридный expert-baseline из нескольких независимых оценок:
- Shades-of-Gray;
- White Patch;
- Gray Edge;
- нейтральные полутона;
- safety-guard по найденным лицам.

Результат — только параметры correction pipeline: RGB gains, temperature/tint, confidence и neutralization strength. Пиксели не генерируются ИИ.

Сохранённые пользовательские решения могут персонализировать только силу нейтрализации через существующий Parameter Recommender. Температура/tint остаются измеряемыми параметрами сцены.
