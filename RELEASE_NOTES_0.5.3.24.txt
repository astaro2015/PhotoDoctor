Photo Doctor 0.5.3.24 — Release Notes
Дата: 2026-09-21

База: Photo Doctor 0.5.3.23 FULL_SOURCE.

1. Аудит карты резкости
- Случайный Gaussian/JPEG-подобный высокочастотный шум больше не считается структурной резкостью.
- Добавлена проверка сохранения структуры после мягкого guide-smoothing.
- Оценка acutance нормирована по амплитуде границы: слабоконтрастная, но резкая структура не должна автоматически проваливаться в soft.
- Реальный blur по-прежнему резко снижает локальную резкость.

2. Аудит локального контраста
- Добавлен structural gate: шумная ровная область не считается информативной низкоконтрастной текстурой.
- Подтверждённая noise-map блокирует spatial contrast в той же области.
- Сводная доля low-contrast считается по уникальной площади изображения с перекрывающимся голосованием и значительно меньше зависит от положения объекта в сетке.

3. Аудит локальных тонов
- Покрытие категорий считается по уникальной площади кадра, несмотря на перекрывающиеся окна.
- Просто яркие, но неклиппированные области больше не маркируются как clipped_highlight.
- Небольшой белый/чёрный участок не присваивает экстремальный статус целому окну без достаточной статистической поддержки.

4. Spatial White Balance / Color v1
- Добавлен локальный анализ цветового освещения поверх глобального WB Advisor.
- Классификации: mixed_light, local_cast, uniform и uncertain.
- Для mixed-light используется общая базовая WB-поправка + плавное spatial-поле остаточных поправок; независимый WB каждой клетке не применяется.
- Локальные поправки допускаются только при согласованной поддержке нескольких окон.
- Добавлен spatial-coherence gate: один лишь разброс локальных AWB-оценок больше не считается доказательством нескольких источников света.
- Hybrid-only режим без настоящих нейтральных опор стал существенно строже; насыщенные цветные мозаики/объекты не должны притворяться mixed-light.
- Сильный cast, при котором кожа выходит из классического YCrCb skin-range, больше не отключает защиту лица: весь face ROI умеренно защищает локальный residual, skin-пиксели защищаются сильнее, глаза — отдельно.
- Validator при отсутствии классической skin-mask использует внутреннюю часть подтверждённого лица и не трактует «кожа не распознана» как автоматическую безопасность.
- Coverage spatial-WB считается по local_strength, а не по одному каналу target_log_r.
- Spatial WB остаётся Review/Preview: auto_eligible=false до независимой экспертной валидации достаточной точности.
- Значение температуры для готового JPEG — эквивалентная поправка color-temperature slider, а не физически измеренная CCT источника.

5. План коррекций / UI
- Заголовок `Сила` переименован в `Сила по мнению ИИ`.
- Дублирующий столбец `Совет ИИ` полностью удалён.
- `spatial_white_balance_v1` отображается как локальная коррекция по `Авто-маске`; глобальный WB остаётся fallback для равномерного освещения.

- Профильный WB/Planner/Validator/Decision: PASS.
- GUI/presentation/reliability: PASS.
