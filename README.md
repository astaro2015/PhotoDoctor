# Photo Doctor 0.5.16

Photo Doctor — локальное Windows-приложение для анализа фотографий и безопасной коррекции изображения. Исходный код выпуска 0.5.16 находится в `src/photodoctor`.

## Возможности

- Анализ качества фотографии и диагностические карты.
- Предпросмотр и сохранение исправленной копии.
- Работа с сериями фотографий и локальная база результатов.
- Дополнительные AI-компоненты через ONNX Runtime; исходный файл не отправляется в облако приложением.
- В версии 0.5.16 кнопки «Открыть», «Сохранить» и «Предпросмотр» используют единый вид кнопок с видимыми подписями. «Открыть» и «Сохранить» расположены слева, «Предпросмотр» — справа.

## Требования

- Windows 10/11 x64.
- Python 3.12 (64-bit).
- Для запуска из исходников установщик загружает и устанавливает Python-зависимости проекта.

## Запуск в Windows

1. Распакуйте проект в папку, доступную для записи.
2. Запустите `START_PhotoDoctor.bat`.
3. При первом запуске скрипт подготовит виртуальное окружение и зависимости, затем откроет приложение. Последующие запуски используют созданное окружение.

Журналы первичной установки сохраняются в `setup.log`.

## Запуск вручную

Из корня проекта в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[ai]" PySide6
.\.venv\Scripts\python.exe -m photodoctor
```

Для сборки Windows-приложения используйте `BUILD_EXE.bat` или `scripts/build_exe.ps1` после установки зависимостей сборки.
